One museum placard for an ordinary office object, treated as an ancient
artifact, for make.fun's "Office Artifacts: The One-Line Placard Contest":
a stapler recast as a ritual binding device, with a catalogue date, a
material, and a donor — deadpan, in a single line of at most 180 characters.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–180 characters), and writes the same bytes on every run.
